# DIIA
DIIA is a domain-isolated interrupt architecture that enforces cross-domain delivery isolation while enabling dynamic interrupt-file allocation.

## Branch
- AIA: For the AIA implemntation provided by OpenXiangshan, we made minor parameter adjustments to compare it with our method.
- AIA-with-DynamicTag: Our DIIA method.
- Smmtt: We implemented a two-domain version based on the smmtt/smsdia standard to compare with our method.
- XiangshanAIA: For the XiangshanAIA implemntation provided by OpenXiangshan, we made minor parameter adjustments to compare it with our method.
